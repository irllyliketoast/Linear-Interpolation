# Linear Interpolation

**Goal:** Implement linear interpolation in C++  
**Language:** C++  
**Course:** Computer Graphics  
**Objective:** This program demonstrates linear interpolation, which is a method of estimating values between two known data points. It’s commonly used in computer graphics, animation, and various computational applications.  
**To Run the Program:**  
1. Copy the provided C++ code into Notepad++ or your preferred text editor.  
2. Save the file with a `.cpp` extension.  
3. Open MSYS2 MINGW64 terminal.  
4. Navigate to the directory containing your file and compile the code using the following command:  
   ```bash
   g++ -o linear_interpolation your_file_name.cpp
   ```  
5. After compilation, run the program by executing:  
   ```bash
   ./linear_interpolation
   ```  
   
This process allows you to visualize the results of linear interpolation based on the inputs provided in the program.
